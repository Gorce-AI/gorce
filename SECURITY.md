# Security Policy

## Scope

The project is a v0.1 scaffold and does not yet provide runtime security
behavior. This policy covers vulnerabilities in the repository, build
configuration, and future implementation.

## Reporting

Do not disclose suspected vulnerabilities in a public issue. Use the
repository's private security reporting channel when it is enabled. Until
then, contact the maintainers privately through the repository owner and
include a description, impact, reproduction steps, and suggested mitigation.

Please do not include credentials or other sensitive data in a report.

## Response

Maintainers will acknowledge a report as soon as practical, assess severity,
coordinate a fix, and publish a security advisory when appropriate. Reporters
will be credited unless they request otherwise.
