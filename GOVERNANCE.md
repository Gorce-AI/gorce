# Governance

Gorce is maintained in the open by its contributors. The maintainers are
responsible for project direction, release decisions, and repository health.

## Decision making

Technical decisions should be discussed in issues or pull requests and
recorded in an ADR when they affect architecture or long-term compatibility.
Maintainers seek consensus and may make a final decision when consensus is
not practical.

## Maintainers

Maintainers review contributions, protect the project standards, and manage
releases. New maintainers are invited by existing maintainers based on sustained
technical contributions, sound judgment, and respectful collaboration.

## Changes to governance

Changes to this document require a reviewed pull request and approval from the
current maintainers.
